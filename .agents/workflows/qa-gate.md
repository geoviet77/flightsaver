---
description: Автоматическая проверка кода перед отчетом пользователю
---

1. Запустить проверку типов TypeScript: `npx tsc --noEmit`.
2. Запустить юнит- и интеграционные тесты: `npm test` или `vitest run`.
3. Запустить релизную сборку: `npm run build`.
4. Проверить git diff на предмет случайного изменения стилей и компонентов UI (UI Freeze).
5. При наличии хотя бы 1 ошибки вернуть задачу соответствующему Лиду на исправление.
