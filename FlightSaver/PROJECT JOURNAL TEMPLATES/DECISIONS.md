### ADR-050: Отказоустойчивый Middleware с защитой try/catch
- **Контекст:** Устранить падение `500: MIDDLEWARE_INVOCATION_FAILED` при обработке запросов в Edge Runtime.
- **Решение:**
  - В `middleware.ts` внедрена правильная мутация `supabaseResponse` внутри `setAll`.
  - Весь код обернут в `try / catch` с безопасным пропуском `NextResponse.next({ request })` в случае непредвиденных сбоев, обеспечивая работу клиентского guard в `page.tsx`.
- **Статус:** Реализовано в v8.16.0.

### ADR-051: API-эндпоинт автодополнения аэропортов и городов (Duffel Places Suggestions API)
- **Контекст:** Реализовать высокопроизводительный серверный маршрут `/api/airports` для быстрого поиска и автодополнения городов и аэропортов по IATA-коду или названию.
- **Решение:**
  - Создан эндпоинт `app/api/airports/route.ts` с GET-обработчиком.
  - Добавлена валидация входного параметра `q` (ранний возврат пустого списка `{ places: [] }` при длине строки < 2).
  - Интегрирован вызов Duffel Places Suggestions API (`https://api.duffel.com/places/suggestions?query=...`) с авторизацией по токену `DUFFEL_ACCESS_TOKEN` и заголовком `Duffel-Version: v2`.
  - Реализован маппинг в унифицированный контракт `{ places: [{ id, name, iataCode, cityName, countryCode, type }] }`.
  - Добавлены интерфейсы `PlaceSuggestion` и `AirportSuggestionsResponse` в `lib/types.ts`.
- **Статус:** Реализовано в v8.17.0.

### ADR-052: Интеграция автодополнения городов и аэропортов в интерфейс поиска AIInputBar
- **Контекст:** Пользователю необходим плавный, визуально привлекательный и отзывчивый поиск городов и аэропортов с подсказками IATA-кодов прямо в основном поле ввода.
- **Решение:**
  - В компонент `components/AIInputBar.tsx` интегрировано плавающее выпадающее меню с подсказками локаций.
  - Настроен debounce 300 мс для оптимизации сетевых запросов.
  - Реализована полноценная поддержка навигации с клавиатуры (`ArrowUp`, `ArrowDown`, `Enter`, `Escape`) и закрытия по клику вне области (`click outside`).
  - Отображаются визуальные бейджи типов («Город» / «Аэропорт»), акцентные IATA-коды (`MOW`, `SVO`, `BKK`) и географическая привязка.
  - Добавлена нормализация и транслитерация русскоязычных названий городов в маршруте `app/api/airports/route.ts`.
- **Статус:** Реализовано в v8.18.0.
