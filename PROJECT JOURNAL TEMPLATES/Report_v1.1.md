## 1. Выполненные задачи и реализованные модули

1. **Парсинг естественного языка (`lib/nlpParser.ts`):**
   - Функция `parseTravelQuery(text: string): ParsedSearchParams`.
   - Распознавание городов/аэропортов вылета и прилёта с учётом русских падежей и предлогов («из Москвы в Бангкок», «в Нячанг из Питера», «в Стамбул», «на Пхукет»).
   - Обработка дат, месяцев и длительности («в ноябре», «на 2 недели», «на выходные», «завтра»).
   - Распознавание бюджетных лимитов («до 80 тысяч», «до 1000$», «до 500 евро»).
   - Определение состава пассажиров («на двоих», «с ребенком», «семья с 2 детьми»).
   - Автоматическая подстановка дефолтного города вылета (Москва / MOW) с меткой `isOriginDefaulted`.

2. **Голосовой ввод (`hooks/useSpeechRecognition.ts`):**
   - Интеграция с Web Speech API (`window.SpeechRecognition` / `window.webkitSpeechRecognition`).
   - Управление состояниями: `isListening`, `transcript`, `interimTranscript`, `error`, `isSupported`, `language`.
   - Поддержка языков `ru-RU` и `en-US`.
   - Безопасные проверки SSR (Next.js).

3. **Центральная поисковая строка и Главный экран (`components/AIInputBar.tsx`, `components/VoiceButton.tsx`, `app/page.tsx`):**
   - Минималистичный интерфейс в стиле Google / AI-First (одна центральная строка ввода высотой 64–68px).
   - Анимированная кнопка микрофона с пульсирующей индикацией при записи.
   - 3 интерактивных чипа популярных сценариев (`components/QuickSuggestions.tsx`).
   - Переключатель режима для слабовидящих (крупный шрифт + максимальный контраст WCAG AAA).

4. **Карточки результатов и прозрачный расчёт (`components/FlightCard.tsx`, `components/PriceBreakdownModal.tsx`, `components/FlightResultsList.tsx`):**
   - Крупная типографика маршрута (22–24px).
   - Блок сравнения цен с ярким бейджем экономии (например, «Экономия: 32 000 ₽ (-41%)»).
   - Зачеркнутая цена классических агрегаторов.
   - Единая главная кнопка действия «Выбрать этот рейс» (высота 52px).
   - Модальное окно прозрачной расшифровки цены («ℹ️ Прозрачный расчёт») с детализацией по сегментам и тарифам.
